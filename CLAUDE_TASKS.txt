R-5b. LISTEN/NOTIFY: слушатель и пробуждение воркеров
================================================================================
Цель: воркеры просыпаются по NOTIFY, а не по таймеру раз в 20 секунд.
Сделай:
- Отдельная горутина с ОДНИМ выделенным прямым (не pooler) соединением, как
  уже сделано для миграций, слушает каналы из R-5a (`pgx`/`lib/pq` listener,
  смотри что используется в проекте). Переподключение с паузой при обрыве.
- При уведомлении будит воркеры (канал `chan struct{}` с буфером 1).
- Основной цикл воркера: по сигналу ИЛИ по запасному таймеру 3 минуты
  разбирает очередь `for { job := claim(); if job == nil { break } ... }`.
- Убери опрос каждые 20 секунд. Graceful shutdown и возврат задачи при
  SIGTERM сохрани.
- Опиши в одном абзаце в README, что нужна прямая строка подключения.
Готово, когда: задача подхватывается сразу после NOTIFY, при пустой очереди
БД не опрашивается чаще раза в 3 минуты.
